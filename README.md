# Production Metadata Review Skill

An open Agent Skills-compatible workflow for reviewing a local production
metadata manifest before handoff or publication. Published by
[SHAR Production](https://sharprod.com/), an AI-hybrid video production studio.

The skill instructs an agent to validate required fields, production stage and
rights status, report only observed findings, and stop a release recommendation
when rights are unknown. Its companion script is dependency-free Node.js.
